# diamond\cyan r9

This is a version of the diamond\cyan mirroring keyboard layout to be used with keyboards that use split spacebars such as Alice Layout Keyboards or other ergonomic keyboards with thumb keys, r9 refers to the 'r' key being used with your thumb and '9' refers to using 9 fingers and 1 thumb and not 8 fingers and 1 thumb.

Here is a screenshot of the layout by using the analytical data from the webpage [created by cyanophage on github.](https://cyanophage.github.io/)

![image of diamond\\cyan r9 version heatmap](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_cyan_r9_heatmap.jpg)

![image of diamond\\cyan r9 version bigram frequency](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_cyan_r9_bigram_frequency.jpg)

Note that you cannot remap keys on the above image, only swap them around.

The reason for the creation of this layout was from learning about a website that ranks keyboard layouts based on three presets: balanced, low pinky and comfort. I decided to follow the weighting for the scoring on the attributes it highlighted especially same finger bigrams, scissor keystrokes, rolls ins and low pinky finger usage outside the home row. The result is a keyboard layout I did not expect but still managed to maintain my design philosophy of keeping low rates of lateral stretch bigrams and ring finger lateral stretch bigrams.

The website that ranks keyboard layouts I mentioned is listed here: [https://altalpha.timvink.nl/](https://altalpha.timvink.nl/)
