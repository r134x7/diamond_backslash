# diamond\orange ergonomic version

The diamond\orange mirroring keyboard layout can only work with ergonomic keyboards hence there is no row-staggered version because this keyboard layout strictly requires a thumb key for the letter 'E' to work.

Here is a screenshot of the layout by using the analytical data from the webpage [created by cyanophage on github.](https://cyanophage.github.io/)

![image of diamond\\orange ergonomic version heatmap](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_orange_ergonomic_heatmap.jpg)

![image of diamond\\orange ergonomic version bigram frequency](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_orange_ergonomic_bigram_frequency.jpg)

Note that you cannot remap keys on the above image, only swap them around.

This keyboard layout was designed to see if I could reach the lowest word effort rating and lowest total word rating efforts possible on the analytical website from cyanophage on GitHub already listed above.

Its word effort rating matches that of diamond\red ergonomic but also reaches a total word effort rating even lower than diamond\black ergonomic.

Therefore, it has the lowest word effort and total word effort scores out of all the diamond\ mirroring keyboard layouts.
