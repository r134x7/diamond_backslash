# diamond\red ergonomic version

This is an ergonomic version of the diamond\red mirroring keyboard layout to be used with ergonomic keyboards.

Here is a screenshot of the layout by using the analytical data from the webpage [created by cyanophage on github.](https://cyanophage.github.io/)

![image of diamond\\ ergonomic version](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_ergonomic_heatmap.jpg)

Note that you cannot remap keys on the above image, only swap them around. So the keys to pay attention to start from the column containing the '.', 'I', 'E' keys and going all the way to the right end. The only key to pay attention to on the fourth row (bottom) is the 'E' key as that key is pressed with your left thumb.

Just like the diamond\ ergonomic version, minimal changes are made to the diamond\red ergonomic layout to improve the performance of the layout in ergonomic keyboards.
