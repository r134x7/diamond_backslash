# diamond\crimson n9

This is a version of the diamond\crimson mirroring keyboard layout to be used with keyboards that use split spacebars such as Alice Layout Keyboards or other ergonomic keyboards with thumb keys, n9 refers to the 'n' key being used with your thumb and '9' refers to using 9 fingers and 1 thumb and not 8 fingers and 1 thumb.

The diamond\\crimson mirroring keyboard layout can only work with ergonomic keyboards hence there is no row-staggered version because this keyboard layout strictly requires a thumb key for the letter 'N' to work.

![image of diamond\\red old version used on keybr dot com](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/keybr_diamond_backslash_red_1.jpg)

I still remembered that the 'G' key on the left side increased the Alternating Hand rates more than 'H' and lowered finger usage on the left middle finger. As I have been learning diamond\\pink n9 and diamond\\orange e9, I am once again preferring diamond\\pink n9 despite diamond\\orange having better word effort ratings because of what has become my preference for keyboard layouts with: low finger distance travelling, low redirect rates and high alternating hand rates.

Since I couldn't increase diamond\\pink n9's total alt rates over that of Dvorak (it is less than 1% difference, see stat images below), I went to see if I could try something different and bring back 'G' onto the left side and trying to not just create an 'HRL' column on the right index finger (because it would create a lot of finger distance travelling) provided results I didn't expect which was, total alt rates higher than Dvorak and, finger distance travelling that is even lower than diamond\ e9. This resulted in the creation of diamond\\crimson n9 and I gave it that name since diamond\\red n9 was already taken and I still wanted to use a red name since it was based on the old version of diamond\\red above.
