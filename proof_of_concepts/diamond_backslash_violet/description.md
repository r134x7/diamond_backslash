# diamond\violet mirroring keyboard layout kbd file

The kanata.kbd file is being used as a proof of concept to demonstrate
how the diamond\violet mirroring keyboard layout works.

More details including bugs are in the kanata.kbd file.

The kanata.kbd file is used with Kanata, see Kanata repo source for how Kanata works: https://github.com/jtroo/kanata

Source of images below: [https://cyanophage.github.io/](https://cyanophage.github.io/)

## finger bigram frequency

Note: 1 to 4 are the left hand fingers from pinky to index for each column they use on the keyboard, 7 to 10 are the right hand fingers from index to pinky for each column they use on the keyboard.
