# diamond\yellow r9

This is a version of the diamond\yellow mirroring keyboard layout to be used with keyboards that use split spacebars such as Alice Layout Keyboards or other ergonomic keyboards with thumb keys, r9 refers to the 'r' key being used with your thumb and '9' refers to using 9 fingers and 1 thumb and not 8 fingers and 1 thumb.

Here is a screenshot of the layout by using the analytical data from the webpage [created by cyanophage on github.](https://cyanophage.github.io/)

![image of diamond\\yellow r9 version heatmap](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_yellow_r9_heatmap.jpg)

![image of diamond\\yellow r9 version bigram frequency](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_yellow_r9_bigram_frequency.jpg)

Note that you cannot remap keys on the above image, only swap them around.

The reason for the creation of this layout was that since diamond\crimson n9 was the layout with the highest total alternating trigram rates for my keyboard layouts. I wanted to see if I could get really low redirect rates with all the knowledge I have gained so far and this is the result.

The website that ranks keyboard layouts I mentioned is listed here: [https://altalpha.timvink.nl/](https://altalpha.timvink.nl/)
