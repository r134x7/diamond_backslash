# diamond\green ergonomic version

This is an ergonomic version of the diamond\green mirroring keyboard layout to be used with ergonomic keyboards.

Here is a screenshot of the layout by using the analytical data from the webpage [created by cyanophage on github.](https://cyanophage.github.io/)

![image of diamond\\green ergonomic version heatmap](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_green_ergonomic_heatmap.jpg)

![image of diamond\\green ergonomic version bigram frequency](https://raw.githubusercontent.com/r134x7/diamond_backslash/refs/heads/main/images/diamond_backslash_green_ergonomic_bigram_frequency.jpg)

Note that you cannot remap keys on the above image, only swap them around.

Just like the diamond\ ergonomic version, minimal changes are made to the diamond\green ergonomic layout to improve the performance of the layout in ergonomic keyboards.
